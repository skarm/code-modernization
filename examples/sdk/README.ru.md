# Входы для координатора

[English](README.md) | **Русский**

Эти JSON демонстрируют контракт runner, а не готовые входы для произвольного репозитория.
Координатор должен построить их по реальному workspace и текущим решениям пользователя.
Пользователь обычно вызывает `$modernize`; самостоятельно писать эти JSON не требуется.

Запуск после проверки входа (из корня установленного плагина):

```bash
node scripts/modernize.mjs run --workspace /absolute/workspace --system my-service \
  --source /absolute/source --workflow extract-rules --input /absolute/prepared-input.json
```

`candidate` считается от workspace. `contextFiles`, gate.file и evidenceFile — от
analysis/<system>. Пути modules.files — от исходников. Unit/service.path — от candidate;
это существующие непересекающиеся подкаталоги. Их создаёт координатор в безопасной копии.
Пути system.source портфеля — абсолютные либо от workspace.

Все `REPLACE_...` — placeholders, а не утверждения о версиях, файлах или наличии одобрения.
Никогда не копируйте quote-плейсхолдеры в человеческие документы, чтобы обойти проверку.
Подставляйте только подлинное, относящееся к текущей фазе решение человека. Для записывающих
запусков нужен дополнительный `--allow-writes`; этот флаг не заменяет исходные human gates.

`extract-rules-lenses.json` запускает не полный AST-анализ, а ограниченные тематические
проходы. Признаки неполноты следует сохранить. `role-task.json` — read-only анализ.
`role-task-transform-tests.json` показывает ограниченную запись characterization tests.
`role-profiles.json` передаётся через `--roles`, а не как workflow input; при необходимости
добавьте `model` только с реально доступным вам идентификатором. Настройки effort должны
поддерживаться выбранной моделью; адаптер не утверждает такую поддержку заранее.

Для независимой оценки используйте `independent: true` и новое задание/поток. Это не даёт
другую модель автоматически. Локальные изображения могут быть переданы через `images`
с путями в разрешённых source/analysis/candidate деревьях, без URL и загрузок из сети.

Полный контракт, ограничения и восстановление: [SDK.md](../../references/SDK.md).
